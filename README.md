Generación y clasificación de datos de ventas

¿Cómo convertir archivos de ventas en información organizada y útil?

Este es un proyecto académico desarrollado en Java 8 para la materia de Conceptos Fundamentales de Programación del Politécnico Grancolombiano. Su objetivo es construir, de forma progresiva, una solución que genere datos de prueba, procese información comercial y produzca reportes de vendedores y productos.

## Primera entrega: generación de datos

Esta etapa nos centraremos en el desarrollo de la clase GenerateInfoFiles, encargada de generar archivos de texto plano con información pseudoaleatoria y coherente de productos, vendedores y sus ventas.

Estos archivos servirán como entrada para las siguientes etapas del proyecto, en las que se organizarán las ventas por recaudo y los productos por cantidad vendida.

### Enfoque del proyecto

- Datos coherentes: relaciones consistentes entre vendedores, productos y ventas.

- Código comprensible: nombres descriptivos, organización y documentación con Javadoc.

- Ejecución autónoma: generación de archivos sin solicitar información al usuario.

- Desarrollo por entregas: alcance y avances documentados en cada etapa.

### Tecnologías

- Java 8.

- Eclipse IDE for Java Developers.

- Archivos de texto plano con campos separados por punto y coma. (CSV)
